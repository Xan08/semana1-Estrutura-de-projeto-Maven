# Semana 1 — Maven

## Validação local

Executar os testes:

`mvn test`

Executar todas as verificações do projeto:

`mvn verify`


### Gerar o pacote

Para compilar o projeto, executar as fases anteriores do ciclo de build e gerar o pacote:

`mvn package`

O arquivo gerado ficará no diretório `target/`.
