# Semana 1 — Maven

Projeto criado durante os estudos da Semana 1 de Java Full Stack.

## Objetivos

- entender a estrutura padrão de um projeto Maven;
- configurar o pom.xml;
- compilar código Java;
- executar testes com JUnit;
- gerar um arquivo JAR;
- executar o artefato pela linha de comando.

## Estrutura

```text
src/main/java       Código da aplicação
src/main/resources  Recursos da aplicação
src/test/java       Testes
src/test/resources  Recursos utilizados pelos testes
target               Arquivos gerados pelo Maven
pom.xml              Configuração do projeto Maven
